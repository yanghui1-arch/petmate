# 尤美农场生活验收控制器

在项目目录执行：

```powershell
npm run dev:farm-life
```

会启动独立控制器与透明测试桌宠，无需先启动正式游戏；关闭控制器退出。每次运行使用系统临时目录中的新存档，退出清理。不读取当前玩家存档、不初始化 Steam、不上传成就。此入口不会进入正式安装包。

启动成功会在终端显示“验收控制器已显示”，并将控制器放到鼠标所在显示器前方。可操作的是标题为“尤美农场 · 验收控制器”的窗口；透明人物窗口只是演出。

## 最快看效果

1. 勾选“快速查看结果”，点“浇水”“收获”“订单备货”或任意生活事件。
2. 每个按钮先重置并准备合适的隔离场景，再运行真实出行/保存规则；成功后自动打开原农场页面，显示人物和日记。
3. 不勾选快速模式可看对白、换装、推门动画、隐藏和返回。按钮跳过 7 分钟教学等待或 20～35 分钟普通排期，出发对白逐字显示完后停留 1.5 秒，气泡消失便开始 1.1 秒从头到脚扫描换装，接着播放 6.583 秒挥手告别后推门出发。离开时立即复核并保存唯一结果，没有额外六秒工作等待。光带上方换成工作服，下方保留原时装；换完全身后才显示门并播放视频。使用已确认的 79 帧、12 fps 透明视频，全程原速。
4. “下一阶段”可跳到出发、提交并停留、离场、返回。真正离开前点“打开农场”取消出发；离开后打开只观看、不取消帮助，原定返回前最后一秒进入也有六秒观看缓冲。

## 规则验收

- 先“准备场景”，再“在当前场景触发”。这会保留该场景的边界条件；不要点击会重新准备正常场景的一键事件按钮。
- 首次收获前、99/499/999 场景尝试触发收获应该失败，打开农场亲自收获才能跨越门槛。
- 11 块亲自浇水场景触发助手浇水后，第 12 块记录为 helper，玩家专属成就仍不完成。
- 今日额度用完、低精力、无候选均显示阻止原因。
- 保存失败：在推门出发阶段结束前开启模拟故障，再推进下一阶段，检查库存/日记没有成功变化；关闭故障尝试恢复存档，再触发。教学失败仍待安排，只有有效结果成功保存才完成。
- 模拟重启保留已提交内容、清理未完成身份；不会重放奖励。
- “8 条未读日记”创建明确的生活展示样例，不改库存；进入农场只逐条播放最近 5 条，弹窗时暂停。
- 动画区只有四个入口：推门去农场、桥边晃腿、门口休息、擦汗与招呼。预览使用临时演出身份，不创建真实出行、不写库存或日记；点“结束预览”恢复原窗口。

## 测试范围

复用 FarmLife、FarmService、FarmLifeDesktop、Farm.vue、Phaser、角色资源和对白。桌面壳是独立动画验收窗口，不启动正式桌宠属性、活动、饥饿提醒等完整模块。低精力/睡眠是控制器模拟的阻止条件；这些真实属性联动仍需正式游戏试玩。Steam 客户端验收也需单独完成。

自动检查：`npm run test:farm-life-lab`。类型检查：`npm run typecheck:farm-life-lab`。
