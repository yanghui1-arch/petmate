- `npm run typecheck`、`npm run build`、`npm run test:farm`、`npm run test:farm-ui`、`npm run test:farm-scene`、`npm run test:farm-assistant`、`npm run test:save-recovery` 均通过。测试使用内存或隔离的 Electron 用户数据，不触碰用户进度。

- 窗口拖动修复：尺寸校正从连续 `move` 改为拖动结束的 `moved`。测试验证拖动过程中不触发调整，完成后小工作区只校正一次。实际多显示器拖动与 DPI 仍需设备试玩。
- 虚拟时钟测试检查应用启动 15 分钟且未打开农场、逐步播种浇水收获交付、用户接管、休息、缺种子、土地全满、订单重算、休眠恢复、请求去重和保存失败回退。
- 加载画面、完整农场与小工作区曾通过隔离截图目视检查；历史截图已从 `spec` 清理。需要重新截图时，可设置 `FARM_SCENE_SCREENSHOT_DIR` 并运行场景测试。
- 全仓 lint 仍失败：原检查记录有 12,451 个错误，本次检查有 12,951 个错误，主要为仓库既有 CRLF/Prettier 格式，另有此前被 eslint 缓存跳过的 003 农场页面。新增的独立助手、运行时、窗口、气泡与共享配置文件定向 lint 为 0 错误（助手构造参数有 5 条已有规则的误报提醒）。未在本次改动中重排全仓格式。
- 待设备试玩：正式 Steam 存档下的窗口跨屏拖动与 DPI、X 关闭同时提交交易、桌宠睡眠/活动与隐藏、跨窗口余额刷新、桌宠气泡实际位置和动画。表中的“部分验证”“待设备试玩”不表示相应功能未实现。
