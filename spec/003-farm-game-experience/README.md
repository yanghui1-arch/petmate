# 尤美农场：方案 A 交互原型

直接用浏览器打开 `prototype.html`，无需启动 Petmate、安装依赖或运行服务器。

这是独立 HTML/CSS/JavaScript 原型，采用新生成的非像素卡通场景与物品图片。场景不放置人物；左上角头像仅作为农场等级入口。所有进度仅存于本页内存，刷新恢复示例数据，没有接入现有应用、IPC、网络请求、存档或支付。

当前背景沿用用户指定参考图的温暖卡通画风、房屋、道路和围栏构图。左上果树林改成扩大的牧场，牧场动物仅作为背景展示；牧场护栏闭合，动物留在栏内。下方池塘码头不放木桶，原型也不预摆木桶。背景选用 `assets/farm-world-lane.png`，此前背景保留作参考。

背景、地块、点击区域和操作反馈共用场景坐标，窗口缩放时保持对齐。12 块土地集中在中央围栏内，外围道路、牧场与池塘不占用种植区域。

地块大小和位置保持不变；农田上方围栏的拐角下移，围栏外增加连接牧场与房屋的土路，减少内部空白。地块悬停不显示额外线框，仅轻微提亮土地，点击范围按土地贴图边缘校正。`prototype-hover.png` 展示悬停效果。

作物使用新制作的 24 个单株阶段素材，存放于六张透明图集 `assets/crop-*-single.png`。每块地按土地透视固定九个种植点；阶段变化只替换单株外形与尺寸，种植点保持不变。图集中的植株间隔并不均匀，因此逐张测量素材区域和源图落地点，不按四等份直接切分。定位记录及渲染方法集中在 `crop-art.js`。

落地点是植株与地面的接触位置：普通植株使用茎基部或根冠，胡萝卜使用根尖，南瓜使用植株与果实的落地位置。叶片可以自然伸出土地，落地点必须留在田内。单株按落地点的前后顺序绘制，摆动和播种动画围绕该落地点进行，不移动根部。此前整片作物图的阶段偏移与成熟阶段整体下移规则已移除。

图鉴、种子选择、商店、背包、订单和收获飞入效果共用同一套素材。缩略图保留原比例，并限制在各株素材区域内。草莓生长中使用独立的开花素材，不再复用旧图集。

`prototype-alignment.png` 展示六种作物的四个阶段，`prototype-root-guides.png` 叠加固定种植点和土地轮廓，标记只用于验收，不显示在实际原型里。

## 体验操作

- 空地：悬停出现种子光标；点击就近展开六种种子，点选后直接种进当前地块。
- 成长中的作物：悬停透明浮框展示状态、剩余时间、预计收成和浇水状态；尚未浇水时出现水壶光标，点击直接浇水。
- 成熟作物：悬停出现采摘手，点击直接收获；收获数量浮起，作物图片飞入背包。
- 未开放地块：绿色草皮覆盖，悬停展示开放等级。
- 金币入口：打开商店，支持选择种子、调整购买数量并扣除演示金币。
- 背包：展示种子和作物图片；支持补货和出售。
- 订单：收集需要的作物后交付，领取金币和经验；可交付数量通过入口角标展示。
- 图鉴：六种作物及每种四个生长阶段的图片、开放等级和演示收获记录。
- 订单、背包、图鉴入口没有圆形底框。布置入口、装饰分类及摆放功能已移除。
- 选种与经营面板：点关闭、点外侧空白、右键或 Esc 退出。经营面板不会挤压场景，地块操作不会打开侧栏。
- 设置：可开启轻柔音效、让示例作物立即成熟或重置原型，用于快速体验不同状态。

操作反馈在地块附近短暂浮起，约 1.3 秒后移除；经营提示在顶部浮起，2 秒后消失。没有固定顶部/底部横条，也没有全田播种、全田浇水按钮。

## 原型边界

演示使用 12 块土地、6 种作物和 3 份示例订单，预置成熟、可浇水、已浇水、空闲与未开放地块。订单交付后只展示待补单状态。

正式页面已按 [spec.md](spec.md)、[plan.md](plan.md)、[tasks.md](tasks.md) 迁移至现有 Vue + Phaser，使用真实农场查询、交易和保存。正式页面设置保留返回、关闭、备份与恢复，不包含原型重置和立即成熟。此前版本未发布，因此本次不做旧农场测试存档迁移。

## 素材与验证

场景、图标和单株素材由内置 imagegen 工具生成，原始生成图保留在工具输出目录。PNG 保持原样，田里的植株以 CSS 取图，缩略图使用 SVG 视窗限制素材区域，不进行脚本图片编辑。最终提示词、生成/编辑模式与输出文件见 `asset-prompts.json`。

在项目已安装依赖的环境中，运行 `node spec/003-farm-game-experience/verify-prototype.cjs`。检查通过独立、隐藏的 Electron 窗口进行，不加载应用入口或 preload，使用一次性临时配置目录。验证记录见 `verification.json`，预览截图保存在本目录。

运行 `node spec/003-farm-game-experience/inspect-crop-assets.cjs` 可检查六张 PNG 的透明通道、四株主体、素材区域和落地点像素；不会修改图片。素材校准记录见 `asset-calibration.json`。界面验证同时检查 24 个阶段的全部 216 个落点，按场景像素计算定位误差，并回归播种、浇水、收获、图文面板和 800×600 窗口。坐标误差通过不代替目视验收，需结合两张对齐图检查实际根部、果实与地面的接触效果。
