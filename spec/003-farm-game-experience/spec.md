# 003 农场游戏体验

状态：方案 A 已批准并实施，自动验收通过。用户确认此前版本未发布，本次无需旧农场测试存档迁移或兼容。

## 背景

原有农场使用像素场景、顶部与底部横条、工具选择和地块侧栏，操作偏管理系统。已确认的独立原型采用卡通等距农场、浮动入口、地块直接操作和悬停信息；本次将其接入实际页面。

## 目标

1. 让玩家在场景中直接完成选种、浇水、收获，不需要先选工具或打开侧栏。
2. 完整采用已确认的背景、道路、围栏、牧场与单株作物素材，保持各阶段根部对齐。
3. 移除布置及装饰经营功能，订单、背包、图鉴入口不再使用圆形底框。
4. 使用真实主进程交易、库存、成长、订单与存档，沿用 001 的作物、教学、等级、收益、补单规则。

## 范围与功能

- Vue 承载悬浮 HUD、信息框和经营弹窗，Phaser 承载背景、土地、作物、命中与反馈。保留现有技术栈。
- 使用 farm-world-lane.png；牧场动物只作为背景，场景没有人物。头像保留为等级入口。
- 12 个等距地块共用场景坐标和土地多边形。窗口缩放时背景、作物、命中位置一起缩放；不画选中矩形或菱形线框，仅轻微提亮土地。
- 场景等比铺满窗口，按中心裁切边缘装饰，不拉伸；去掉上下模糊补边，所有地块和交互保持可用。
- 6 种作物各有 4 阶段，每地 9 个固定种植点。源图使用已测量区域和根部坐标，按根部前后顺序绘制；阶段变化不改变落地点。
- 未开放土地由绿色草皮覆盖，悬停展示开放等级。
- 悬停已种地块约 250ms 后显示半透明浮框，包含作物、阶段、剩余时间、进度、预计数量及浇水状态。离开或打开面板关闭浮框。
- 空地显示种子鼠标图标；点击就近打开种子选择卡片，展示图片、库存、成长时间、教学剩余次数和未解锁状态。选择可用种子立即播种当前土地，成功后关闭。补货进入商店。
- 生长作物未浇水时鼠标显示水壶图标，点击直接浇水；已浇水不重复请求。成熟作物鼠标显示采摘手，点击直接收获。
- 订单、背包、图鉴使用无圆形背景的图标与文字；订单角标展示可交付数量。右上角使用商店图标和余额，不显示加号，点击打开商店。头像复用现有尤美头像，点击打开等级进度。
- 悬停可操作土地时，隐藏系统鼠标，种子、水壶、采摘手跟随鼠标实际位置。用各图标的散落种子、壶嘴、指尖作为热点，对齐鼠标尖端；图标不拦截输入，点击仍按鼠标实际位置命中。离开地块、悬停已浇水或未开放地块、打开弹窗后隐藏图标并恢复普通鼠标。
- 订单、背包、图鉴、商店、交易和设置以覆盖式弹窗展示，页面无固定横条、底部工具栏或地块侧栏。
- 背包仅保留种子与作物；种子提供补货，作物可出售。商店仅售种子。图鉴展示作物图片、四阶段、等级与真实累计收获。
- 出售选好数量后点击一次确认即提交，当前订单需要该作物也不显示提醒或拦截；保留主进程库存、数量、版本和保存检查。
- 动态背景方案已取消，spec005 和相关实验文件清理；正式页面继续使用现有静态背景。
- 移除装饰商品、库存、摆放、移动、回收、工具状态以及对应交易能力。无需旧数据迁移，也不读取或清除用户整份真实存档来完成开发。
- 设置提供返回、关闭窗口、备份与恢复入口；保留整体备份、恢复预览及确认。原型的重置、立即成熟等演示功能不进入实际页面。
- 成功保存后才展示资源与收获反馈：地块附近反馈短暂上浮约 1.3 秒；收获图片飞入背包；顶部经营提示 2 秒消失。错误提示可见且不改变场景尺寸。
- 浇水成功保存后，在对应地块中心播放 5 个蓝色水滴撒落动画，约 1 秒后淡出，并自动清理。特效不拦截鼠标，不改变页面布局；保存失败、保存等待中及重复点击已浇水作物不播放。系统开启减少动态效果时隐藏水滴动画。
- 交易期间阻止重复请求；主进程仍校验库存、余额、等级、版本和请求唯一性。失败不扣资源，不显示成功动画；跨窗口余额变化及时刷新。
- 支持简体中文、繁体中文和英文；800×600 最小窗口能操作全部地块和面板。默认窗口沿用 1080×720。
- 独立无边框窗口保留顶部空白区域拖动能力，拖动区域没有可见横条，不覆盖入口或农田。

## 工作流

进入农场 → 查询真实农场状态 → 显示全屏场景和浮动入口。

空地悬停 → 鼠标变为种子图标 → 点击打开选种 → 选择种子 → 主进程保存交易 → 更新土地和库存，显示短暂反馈。

生长作物悬停 → 查看详情 → 未浇水时点击浇水 → 保存成功后更新状态；成熟时点击收获 → 保存成功后清空土地、增加库存经验并播放收获反馈。

经营入口 → 覆盖弹窗 → 查看图片和真实数据 → 购买、出售或交付 → 保存成功后更新；点击外侧、关闭、右键或 Esc 退出。

## 验收

1. 实际农场使用确认的卡通背景与素材，没有人物、固定横条、底栏、侧栏及布置入口。
2. 三个侧边入口无圆形底框，点击区域可靠，订单角标准确。
3. 12 个土地命中区域与贴图重叠，悬停无额外边线；绿色锁定地无法播种。
4. 6×4 阶段全部 216 个根部保持固定种植点，透视和前后遮挡正确。
5. 空地点击即可选种；未解锁、缺种子、保存故障均阻止提交；教学额度正确消耗。
6. 浇水无需选择工具，已浇水不重复提交；成熟点击直接收获，不重复发奖。
7. 悬停浮框包含真实成长信息且不挡操作；窗口边缘浮框和选种框不越界。
8. 真实订单交付、补单、购买、出售、图鉴、等级及跨窗口余额正常。
9. 装饰相关页面、状态和操作全部移除；主进程拒绝装饰交易。
10. 反馈自动移除；失败保留资源，面板与交易期间不操作底层场景。
11. 设置可返回、关闭和进入真实备份恢复，不包含演示修改进度入口。
12. 简繁英及 800×600、1080×720、宽屏验证通过；卸载重新进入无重复画布、监听或计时器。

本 spec 覆盖 001/002 中与像素风、工具栏、地块侧栏及装饰相关的要求；其他玩法与存档可靠性要求继续适用。
