## 已确定方案

采用“场景标识常驻 + 悬停反馈 + 点击筹备提示”。名称为牧场、探索、小屋、钓鱼，四处统一处于暂未开放状态。按用户最新反馈，牧场牌上移，钓鱼牌放最新截图红框标出的码头上方岸边，探索牌放路旁草地，小屋取消木牌、直接在门上加锁。

沿用现有 Vue + Phaser。Vue 承载木牌和提示，Phaser 保留场景渲染及场景区域命中，两侧使用同一份入口定义与场景坐标。木牌可用现有配色及 CSS/SVG 表现，不需要重绘背景、生成新场景图或增加依赖。

此前的仅悬停才显示入口方案容易被玩家当作背景装饰，用户已选择常驻木牌方案，不再重新开启方案选择。

## 代码现状与影响范围

- `src/renderer/game/farmSceneModel.ts` 定义 1600×900 背景世界尺寸、场景布局、农田坐标和土地命中，目前目标类型只有地块与空白。
- `src/renderer/game/FarmScene.ts` 负责背景、作物、鼠标和场景事件；作物按不透明像素命中，土地按多边形命中。
- `src/renderer/components/farm/FarmScene.vue` 转发场景事件并管理启动、大小变化及销毁。
- `src/renderer/views/Farm.vue` 承载 HUD、悬停、选种、经营弹窗、临时反馈及玩家手动活动记录。
- 简繁英文案位于 `src/renderer/i18n/locales/`；真实页面和场景测试分别位于 `scripts/test-farm-ui.mjs` 与 `scripts/test-farm-scene.mjs`。
- 本轮不修改农场规则、主进程交易、preload、存档结构、窗口尺寸或助手调度；不修改 `spec/005-farm-video-prototype/` 与视频。

## 实施顺序

### 1. 基线和入口定义

- 记录类型检查、农场页面/场景测试与构建基线，区分现有格式规则问题。
- 在现有场景模型附近集中定义四个稳定入口标识、名称文案键、木牌锚点、场景点击范围和提示锚点。
- 入口采用背景世界坐标，通过背景的平移与缩放定位；不套用只用于农田的 fieldFrame 偏移和缩放。
- 扩展场景目标和悬停信息，明确区分入口、地块与空白，检查所有消费位置，避免把入口标识当作地块编号。
- 开放状态是本轮固定的展示信息，不创建解锁服务、动态注册框架或持久化字段。

### 2. 木牌与场景命中

- 在 Farm.vue 接入 FarmEntrances.vue，由独立组件渲染三个木牌按钮和小屋门锁，管理悬停、点击反馈与定时清理。沿用当前游戏字体，木牌提供名称和锁标记，小屋名称通过悬停及点击展示。
- 使用集中定义的背景锚点映射到页面；限定点击范围，不遮挡现有 HUD、门口和作物。
- 钓鱼锚点按用户澄清代表立柱底部；渲染牌面及提示时扣除按木牌实际缩放计算的立柱落脚偏移，避免误用牌面中心，也避免最小字号缩放导致落脚点漂移。
- Phaser 使用同一入口定义判断背景区域点击，将入口目标交给页面处理。
- 木牌按钮点击、键盘和场景区域点击复用同一处理入口；按钮事件不再次透传成第二次场景操作。
- 保留已有农田不透明像素及多边形命中，不扩大入口热区去抢占作物区域。

### 3. 悬停与鼠标

- 为入口接入悬停状态和约 250 毫秒的提示延时；悬停只提亮木牌。
- 指针在入口范围内使用现有游戏点击手势，隐藏农田操作图标，沿用已修复的全局鼠标样式优先级规则。
- 进入地块、空白、HUD、选种和经营弹窗时正确交接鼠标与悬停状态，不绘制选中线框。
- 触摸点击不生成额外鼠标图标；键盘焦点具有清晰的木牌反馈。

### 4. 点击反馈与生命周期

- 为入口提供靠近地点的轻提示卡片，包含名称及筹备文案；保持最大一张，约 2 秒自动清理。
- 连续点击只替换内容或重新计时，取消旧计时器；悬停提示与点击反馈互斥。
- 提示容器不接收指针事件，不改变画布尺寸，不使用覆盖全场景的遮罩。
- 打开经营面板或选种、右键、Esc、页面销毁时收起并清理入口提示。
- 点击遵循现有场景可操作状态，复用当前手动活动记录，不调用 executeFarm；保留正常交易反馈和保存错误展示。

### 5. 文案与布局

- 补齐简繁英的四个名称、暂未开放和各入口筹备文案。
- 检查小尺寸下的木牌文字与提示边界，用与现有 popover 相容的窗口内定位方式。
- 支持减少动态效果，不额外增加持续动效、红点或假解锁信息。

### 6. 验证与交付

- 扩展场景模型检查：四处世界坐标、命中范围、缩放、空白及农田边界。
- 真实 Vue 页面检查：四种反馈、两秒清理、连续点击替换、关闭操作、键盘、遮罩隔离、交易调用为零，以及现有手动活动记录。
- 实际 Vue + Phaser 的隔离 Electron 检查：原生鼠标点击木牌与场景范围、入口和地块之间的指针切换、尺寸/DPI、提示位置和重复进入。
- 检查默认场景、小工作区尺寸、悬停和点击截图，人工确认木牌融入插画且不挡作物。
- 运行 `npm run test:farm-ui`、`npm run test:farm-scene`、`npm run typecheck`、修改文件 lint、`npm run build` 和 `git diff --check`。
- 场景测试和构建串行执行，避免同时改写自动生成的声明文件。测试使用隔离存档，不改写用户真实进度。
