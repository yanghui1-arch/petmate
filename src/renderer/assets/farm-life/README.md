# 尤美农场生活资源

只保留四种演出，统一农场工作服；正常桌面待机、出发前对白和返回复用当前桌宠原模型与服装。

- `departure.webm`：用户确认的新版挥手告别、转身推门视频，1440×1080，隔一帧保留一帧，共 79 帧、12 fps，总时长 6.583 秒，全程原速，只播放一次。去除品红背景与地面粉白光斑，保留蓝色眼睛、粉色蝴蝶结、头发轮廓及暖黄色门光。换装结束再播放，动画结束后隐藏桌宠窗口；动画自身不触发劳动或奖励。
- `bridge.png`：获批桥边坐姿晃腿，23 帧、12 fps，循环。
- `door.png`：获批门口坐姿原图，1024×1536，保留不变。
- `door-display.png`：原图经 Lanczos 平滑缩小为 144×216 的正式静态显示资源，减少大幅 WebGL 缩小时的锯齿；位置、比例和遮挡沿用原参数。
- `sweat.png`：获批擦汗后打招呼，49 帧，沿用原预览的 8/12 fps 时间表；场景入场播放一次后保持最后的站立微笑帧。数据刷新不重播。
- `timing.json`：生产播放时间表；图集每帧 144×216、每行 8 列。
- `desktop-workwear.png`：工作服静态参考。桌面和验收壳在出发前保留当前时装，用 1.1 秒从头到脚扫描换装逐渐显示视频的工作服首帧，完成再开始进门；不修改玩家时装选择。
- `flower.svg`：原固定小花，不是角色动作。

位置采用用户导出的 1280×720 参数，正式 1600×900 场景按 1.25 换算后随场景整体缩放。人物不参与地块命中，不挡操作。

使用 `scripts/prepare-farm-life-assets.py` 从已批准的本地资源打包；不会调用生成模型。当前出发资源来自 spec008/desktop-departure/magenta-v2/departure-magenta-alpha-12fps.webm，抠图脚本和源视频保存在 spec008。旧三服装八动作图集、旧动作组件及生成脚本已删除，旧动作视频样片已删除。

透明视频回归检查：本地保留 video-playback.mp4 源视频时，运行 `python -B scripts/test-farm-departure-alpha.py --video src/renderer/assets/farm-life/departure.webm`，对照源片每隔一帧的蓝色虹膜、蝴蝶结、头发、背景/地面与暖黄色门光，检查最终编码后的透明通道和 79 帧数量。实际播放器与换装衔接使用农场生活验收控制器检查。
